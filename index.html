Install

Skills activate automatically from natural language once installed. Two ways to add them:

Recommended — Claude Code plugin
/plugin marketplace add Wolfe-Jam/faf-skills

Then /plugin install faf@faf-skills — or just /plugin → Discover. Installs the whole set; new skills arrive on update.

Manual — git clone
git clone https://github.com/Wolfe-Jam/faf-skills.git && cp -r faf-skills/skills/* ~/.claude/skills/

Restart Claude Code. Skills activate automatically; call one directly with /faf-expert.

Prerequisite: npm install -g faf-cli  ·  or brew install wolfe-jam/faf/faf-cli
